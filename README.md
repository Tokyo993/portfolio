# Nikita Masyukevych — Backend & AI portfolio

Responsive static portfolio with English, German and Russian translations. No build step is required. Open index.html or serve this directory with a local HTTP server.

Deploy on Vercel using Framework Preset Other, with no build command. Keep the existing domain configuration and preview the branch before merging it into the production branch.

Project artwork is built with CSS, rather than screenshots. Core content is present in the HTML and remains readable with JavaScript disabled. Language preference is saved locally, and language switching also works if storage is unavailable.

Content follows the supplied resume. Independent development dates use 2025 instead of the old website's 2022. Hotel-agent copy describes the supplied project and visible demo without claiming production adoption or unverified architecture. UE 5.8 is the version supplied by the author.
